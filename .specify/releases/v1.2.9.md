# Release Notes: v1.2.9

**Date**: 2026-11-02 | **Previous**: v1.2.8 | **Commits**: 2 | **Tests**: 600 → 618

## Highlights

### Remote Clipboard over SSH (OSC 52)
- Added native OSC 52 terminal clipboard escape sequences.
- Copy text on remote servers inside SSH sessions (`echo "hello" | clipcopy`) and paste immediately into your local computer's clipboard without requiring X11 forwarding.
- 4-tier fallback chain: Native desktop GUI → macOS pbcopy → OSC 52 escape sequences → local secure file buffer.

### Headless Server Safety
- System file openers gracefully adapt on headless servers: text files view inside your default terminal pager, while binaries and web URLs return clean error notices rather than hanging headless sessions.
- Added terminal capability detection in `ziro doctor` with per-terminal configuration guidance.
