# Release Notes: v1.2.5

**Date**: 2026-11-01 | **Previous**: v1.2.4 | **Commits**: 1 | **Tests**: 535 → 555

## Highlights

### Universal Secure Directory and File Permissions
- Enforces strict POSIX permissions across all configuration and runtime directories (mode 700) and generated artifacts (mode 600).
- Applies automatically across cache creation, compiled wordcode files, and plugin directories.
- Protects private developer environments and server accounts against unauthorized reading by other local users.

### Diagnostic Permission Audits
- System diagnostics (`ziro doctor`) actively audit filesystem permissions and flag permissive settings with clear fix recommendations.
