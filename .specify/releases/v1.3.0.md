# Release Notes: v1.3.0

**Date**: 2026-11-03 | **Previous**: v1.2.10 | **Commits**: 1 | **Tests**: 623 → 670

## Highlights

### Ghost v2.0.1 Integration
- Fully integrated Ghost v2.0.1 with automated multi-architecture companion binary provisioning (`linux-x86_64`, `linux-aarch64`, `darwin-x86_64`, `darwin-arm64`) verified by SHA256 checksums.
- Modularized autosuggestion into a deferred inline suggestion line and an on-demand Rust Focus Mode popup triggered via the Tab key.
- Diagnostics (`ziro doctor`) directly observe companion binary version and health status.

### AI-Safe System Management Layer (`ziro mcp`)
- Implemented a standard JSON-RPC 2.0 Model Context Protocol (MCP) server providing 16 tools across 5 domain areas:
  1. System inventory (`ziro.system.*`): OS, packages, developer binaries, and secret-redacted environment variables.
  2. Directory awareness (`ziro.dir.*`): Git repository state, file type distributions, and cleanup safety evaluation.
  3. Command safety (`ziro.cmd.*`): Static danger scoring (0-10) and two-step deliberative execution.
  4. Ghost companion proxy (`ghost.*`): Suggestion queries, health diagnostics, and runtime telemetry.
  5. Native shell tools (`ziro.*`): Analyze active plugins, run diagnostics, and inspect metrics.
- Default Safe-Mode strictly prevents mutating command execution without an explicit `--allow-execute` flag.
- Two-step confirmation enforces a 60-second time-limited, single-use token before any shell command can execute.
- Every execution attempt is immutably logged to a private audit trail file (`~/.cache/ziro/mcp/audit.jsonl`, mode 0600).
