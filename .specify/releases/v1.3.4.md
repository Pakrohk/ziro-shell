# Release Notes: v1.3.4 (Hotfix)

**Date**: 2026-11-06 | **Previous**: v1.3.3 | **Commits**: 4 | **Tests**: 687

## Tab now works — permanently

### What was broken (a 3-iteration saga)

- **v1.3.2**: Tab could hang indefinitely on commands like `sudo mkinitcpio -P`. Ctrl+C to escape left a `$(starship prompt ...)` fragment in the buffer.
- **v1.3.3**: attempted async fix broke the popup entirely (TUI needs TTY, got pipe).
- **v1.3.4 (this release)**: confirmed root cause — **the ghost-popup binary does not respond to Ctrl+C**. It hangs until killed externally. Any shell-side fix fails.

### Pragmatic resolution

- **Ghost popup disabled by default** via `_GHOST_POPUP_ENABLED=0`.
- **Tab uses `fzf-tab` completion** — reliable, fast, never hangs.
- **No more `$(starship prompt ...)` fragments** — starship is pre-rendered once per prompt.
- **No subprocess spawn on Tab** — <1ms response.

### What still works

- 54% faster boot (defer micro-decomposition, v1.3.3)
- fzf-tab completion on Tab
- expand-or-complete as final fallback
- All 687 tests passing
- Full doctor health (33/33)

### What's temporarily off

- Ghost popup on Tab. Requires binary fix (SPEC-026 M04a). Will return.
- To test (WILL hang): `export _GHOST_POPUP_ENABLED=1`

## Upgrade

```bash
ziro update && exec zsh
```

**Users on v1.3.3**: update immediately — popup was completely broken there.
**Users on v1.3.2 or earlier**: update straight to v1.3.4. Skip v1.3.3.

## Rollback

v1.3.4 itself is the pragmatic rollback target (Tab works, popup pending).
Older versions had either hang (v1.3.2) or dead popup (v1.3.3).
