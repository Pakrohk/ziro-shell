# Release Notes: v1.3.3

**Date**: 2026-11-06 | **Previous**: v1.3.2 | **Commits**: 9 | **Tests**: 671 → 683

## Highlights

### Shell opens 54% faster

- Interactive prompt: 31.4 ms → 14.4 ms
- Pure boot: 22.1 ms → 10.3 ms
- What changed: the defer engine (1,050 lines inline) became a 17-line queue shim + 5 lazy modules. DAG, timeout, state, telemetry — each wakes up only when needed.
- You feel it every time you open a terminal.

### Tab no longer freezes on Ctrl+C

- **Bug**: pressing Tab on commands like `sudo mkinitcpio -P` could hang the shell indefinitely. Ctrl+C to escape would leave a `$(starship prompt ...)` fragment scattered across the buffer.
- **Fix**: two root causes eliminated.
  - Starship now renders once per prompt (in precmd), not on every keystroke via `$()`.
  - Ghost popup spawns asynchronously via ZLE fd handler — shell returns immediately, no blocking.
- **Your feature stays**: ghost popup still opens as primary on Tab. fzf-tab still works as fallback.
- **Won't regress**: 9 new automated tests (5 static + 4 pty-based interactive) reproduce the exact bug and must pass forever.

### SPEC-027: plugin development contract

- Full contract for plugin authors: capability decomposition, 7 load strategies (eager, deferred, on-demand, service, etc.), shim/service rules, anti-patterns, 5 mandatory tests.
- `docs/PLUGIN-DEV.md` (402 lines) — user-facing guide, no internal jargon.
