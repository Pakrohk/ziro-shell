# Release Notes: v1.2.10

**Date**: 2026-11-03 | **Previous**: v1.2.9 | **Commits**: 1 | **Tests**: 618 → 623

## Highlights

### External Tools Observability
- Added real-time metrics and health aggregation for external shell companion tools.
- New `ziro stats` command displays aggregated event counts, latency, and error metrics across installed tools.
- New `ziro health` command inspects live diagnostic readiness and self-test reports.
- Extended `ziro doctor` with an automated external tools health audit check.

### Standardized Telemetry Protocol
- Any current or future tool that outputs NDJSON metrics to its local cache path is automatically discovered and monitored without code changes.
