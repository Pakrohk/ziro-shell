# Release Notes: v1.2.3

**Date**: 2026-10-31 | **Previous**: v1.2.2 | **Commits**: 1 | **Tests**: 494 → 514

## Highlights

### Secret Leak Prevention in History Cache
- The autosuggestion history cache now detects and redacts 10 distinct secret patterns before writing to disk.
- Filters cloud provider access keys, developer access tokens, private API keys, database connection credentials, and SSH private keys.
- Completely prevents sensitive credentials typed into the terminal from persisting in plain text.

### Private Cache File Permissions
- Enforces strict file mode permissions (read and write for owner only, mode 600) on all history cache files.
- Prevents other local users on multi-user workstations and shared servers from reading command history artifacts.
