# Release Notes: v1.2.2

**Date**: 2026-10-31 | **Previous**: v1.2.1 | **Commits**: 1 | **Tests**: 478 → 494

## Highlights

### Reliable Non-Interactive Shells
- Running automated commands, remote execution over SSH (`ssh host 'ziro doctor'`), cron jobs, and background scripts no longer trigger interactive shell hooks.
- Interactive-only facilities are strictly gated behind shell interactivity checks, eliminating terminal warning noise.

### Boot Configuration Guard
- Validates installation home directories before generating the primary shell boot shim.
- Prevents temporary development directories or automated test runs from corrupting personal startup configurations.
